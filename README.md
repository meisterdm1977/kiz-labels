# Этикетки ЧЗ: хранение и печать

Веб-сервис для хранения готовых этикеток Честного знака из 1С и их печати на TSC.
Работает в браузере (Chrome или Edge), ничего ставить на компьютеры не нужно.

Что умеет:
- загрузка Excel-макета этикеток из 1С: сервис сам читает каждую этикетку и полный код из DataMatrix, проверяет повторы и ошибки;
- поиск по артикулу с размером или сканером баркода;
- печать нужного количества: коды сразу уходят в архив, два упаковщика никогда не получат один код;
- архив с повторной печатью только по личному коду сотрудника;
- журнал (кто, когда, сколько), остатки, выгрузка в Excel;
- архив и журнал хранятся 6 месяцев, потом очищаются сами.

## Запуск на сервере

### Что понадобится
1. **Сервер (VPS)** у российского хостинга (Timeweb Cloud, Selectel, REG.RU и т. п.):
   Ubuntu 24.04, 2 ядра, 4 ГБ памяти, диск от 40 ГБ. Обычно 1000–2000 ₽ в месяц.
2. **Домен или поддомен**, например `kiz.ваш-сайт.ru`. В настройках домена создайте запись типа A
   с IP-адресом сервера. Домен нужен для защищённого соединения (https), сертификат выпустится сам.

### Установка (один раз)
Подключитесь к серверу по SSH (на Mac: программа «Терминал», команда `ssh root@IP-адрес-сервера`,
пароль хостинг присылает на почту) и вставьте одну команду:

```sh
curl -fsSL https://raw.githubusercontent.com/meisterdm1977/kiz-labels/main/install.sh | bash
```

Скрипт сам поставит Docker, скачает сервис, придумает пароли и запустит всё. В конце он покажет адрес сайта,
логин и пароль администратора. Без своего домена адрес будет вида `https://1.2.3.4.sslip.io`.

Со своим доменом (запись A домена должна указывать на IP сервера):
```sh
curl -fsSL https://raw.githubusercontent.com/meisterdm1977/kiz-labels/main/install.sh | DOMAIN=kiz.example.ru bash
```
Сменить домен позже: исправьте `DOMAIN` в `/opt/kiz/.env` и выполните `cd /opt/kiz && docker compose up -d`.

### Резервные копии
```sh
crontab -e
```
Добавьте строку (копия каждую ночь в 3:00, хранятся 14 дней в папке `backups`):
```
0 3 * * * /opt/kiz/backup.sh
```
Лучше раз в неделю скачивать папку `backups` к себе или подключить облачное хранилище хостинга.

### Обновление
```sh
curl -fsSL https://raw.githubusercontent.com/meisterdm1977/kiz-labels/main/install.sh | bash
```

## Первая настройка

1. Войдите как администратор (логин `admin`, пароль из `.env`).
2. **Сотрудники → Добавить**:
   - для каждого упаковщика роль «Упаковщик». Сервис выдаст личный код и бейдж со штрихкодом для печати на TSC;
   - для компьютера упаковки роль «Компьютер упаковки» с логином и паролем. Под ним входят на общем компьютере, а кто печатает, сервис узнаёт по бейджу;
   - для старшего кладовщика и заместителя роль «Оператор».
3. На компьютере упаковки войдите под «Компьютером упаковки» и оставьте браузер открытым.

## Настройка принтера TSC MB240 (один раз на компьютере упаковки)

1. Панель управления → Устройства и принтеры → TSC MB240 → Настройка печати.
2. Размер бумаги: создайте 50 × 104 мм, ориентация книжная.
3. В Chrome при первой печати в окне печати выберите принтер TSC, «Поля: нет», «Масштаб: по умолчанию»
   (или 100%). Chrome запомнит эти настройки.

## Как печатать
1. Найдите товар: введите артикул с размером или отсканируйте баркод.
2. Введите количество, отсканируйте свой бейдж и нажмите «Печать» (или Enter).
3. Откроется окно печати Windows, нажмите «Печать».

Коды уходят в архив в момент нажатия «Печать» в сервисе. Если печать не прошла (нет ленты, принтер выключен,
окно закрыли), откройте **Архив**, найдите эту печать, отметьте нужные коды и перепечатайте по личному коду.
Повреждённую этикетку можно найти в архиве, отсканировав её DataMatrix.

## Для разработчика

Python 3.12, FastAPI, PostgreSQL, LibreOffice (превращает Excel-макет в PDF), libdmtx (читает DataMatrix).

```sh
pip install -r requirements-dev.txt
DATABASE_URL=postgresql://kiz:kiz@localhost:5432/kiz_test python -m pytest tests
```

Настройки (переменные окружения): `ARCHIVE_DAYS` (183), `PRINT_LINK_MINUTES` (10),
`LABEL_WIDTH_MM` / `LABEL_HEIGHT_MM` (50 / 104), `TZ_NAME` (Europe/Moscow), `DEFAULT_MIN_STOCK` (50).
